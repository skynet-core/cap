# Roadmap — amp-vscode

1. **V0:** extension skeleton, executable detection, workspace trust, build/run tasks.
2. **V1:** package/target/profile selector, status bar, multi-root support.
3. **V2:** compdb generation/activation, clangd refresh workflow, diagnostics.
4. **V3:** Test Explorer, debugger launch, sanitizer and profiling commands.
5. **V4:** marketplace packaging, telemetry opt-in policy, remote/WSL and platform testing.

Exit criteria: VS Code extension host tests, integration fixture with clangd, benchmarked activation, and documented permission behavior.
